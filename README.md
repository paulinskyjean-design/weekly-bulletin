# 埔心基督徒聚會處週報 - 手機專用互動資訊網

> **教會年度目標**：《全心倚賴耶和華、一切事上認定主》  
> **出刊期數**：主後 2026 年 10 月 18 日 第 1516 期週報  
> **會堂地址**：桃園市楊梅區埔心文化街 177 號

## 專案特色與亮點

本專案專為**手機直式版面（Mobile Portrait）**量身打造，將傳統紙本或 PDF 週報轉化為色彩明亮、功能豐富且具高度互動性的現代化 Web 應用程式。

1. **手機專用直式體驗 (Mobile-First)**：
   - 採用類似原生 App 的直式版面設計，底部附帶常駐微動態導覽列。
   - 在電腦螢幕上自動居中模擬手機視窗，在手機瀏覽器上貼合全螢幕並支援安全區域（Safe Area Insets）。
2. **大字體與易讀性設計 (長輩友善)**：
   - 預設基礎字體 17.5px，提供「標準 (A)」、「放大 (A+)」、「特大 (A++)」三段即時字級切換，自動儲存至瀏覽器暫存。
   - 選用深灰藍高對比文字與暖白背景，減輕長輩閱讀負擔。
3. **即時全站檢索功能 (Search & Filter)**：
   - 頂部一鍵展開搜尋框，輸入關鍵字（例如：「葉文漢」、「獎學金」、「大掃除」、「代禱」）即時搜尋全週報內容。
   - 自動統計符合筆數，並以鮮豔高亮標註相應文字。
4. **豐富視覺與動畫設計**：
   - 採用溫暖金黃、穩重典雅靛藍、生機翡翠綠、喜樂玫瑰等明亮色彩搭配。
   - 內建平滑展開抽屜、彈跳經文視窗、壽星祝福彩色紙花（Canvas Confetti）。
5. **免外部依賴的 Web Audio 互動音效**：
   - 透過瀏覽器內建 Web Audio API 即時合成音階，無需額外下載 MP3，省流量且完全離線可用。
   - 包含：觸控微音、本週金句清澈水晶鐘聲、代禱「阿們」三和弦、壽星祝賀歡慶琴韻。
   - 頂部設有獨立音效開關（可一鍵靜音/開啟）。
6. **深度互動功能**：
   - **本週金句**：一鍵複製經文文字至剪貼簿、播放心靈祥和鐘聲、彈窗閱讀前後經文（箴言 4:20-23）。
   - **主日崇拜程序**：步驟化時間軸，可收合展開宣召（詩篇95篇）、講道信息及主禱文全文。
   - **守望代禱牆**：按「我已代禱」即發送飄逸愛心粒子與阿們和弦，並即時累計代禱次數。
   - **服事輪值切換**：本週（10/18）與下週（10/25）同工排班一鍵無縫切換。
   - **快速聯絡**：整合一鍵撥打牧者電話、Google 地圖會堂導航路線。

## 上傳 GitHub 與發布 GitHub Pages 教學

請依照以下四個步驟，即可將本專案發布到網際網路供全教會弟兄姊妹在手機上瀏覽：

### 步驟 1：建立 GitHub 儲存庫 (Repository)
1. 登入 [GitHub](https://github.com/)。
2. 點擊右上角的 **「+」** ➔ **「New repository」**。
3. 儲存庫名稱（Repository name）填寫如：`puxin-church-bulletin`。
4. 設定為 **Public**（公開），其餘選項保持預設，點擊 **Create repository**。

### 步驟 2：在本地終端機（PowerShell 或 Git Bash）初始化並推送
在專案目錄下執行以下指令：

```bash
# 1. 進入專案資料夾
cd "c:\Users\USER\Desktop\AI works\週報手機"

# 2. 初始化 Git 儲存庫
git init

# 3. 將所有檔案加入暫存區
git add .

# 4. 提交版本
git commit -m "feat: 初次發布埔心基督徒聚會處手機互動週報"

# 5. 將預設分支命名為 main
git branch -M main

# 6. 關聯到您在 GitHub 建立的遠端庫 (請替換 <YOUR_USERNAME> 為您的 GitHub 帳號)
git remote add origin https://github.com/<YOUR_USERNAME>/puxin-church-bulletin.git

# 7. 推送至 GitHub
git push -u origin main
```

### 步驟 3：開啟 GitHub Pages 免費網站託管
1. 回到 GitHub 儲存庫頁面，點擊上方的 **Settings**（設定）。
2. 在左側選單中找到 **Pages**（位於 Code and automation 區塊）。
3. 在 **Build and deployment** 底下的 **Source** 選擇 **Deploy from a branch**。
4. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**（儲存）。
5. 等候 1～2 分鐘，頁面頂端將出現綠色提示與您的專屬網址：  
   `https://<YOUR_USERNAME>.github.io/puxin-church-bulletin/`

### 步驟 4：產生 LINE 官方帳號或 QR Code 分享
可將產生的 GitHub Pages 網址透過免費線上 QR Code 產生器製作成二維碼，張貼於教會招待處或印製於實體週報上，方便弟兄姊妹直接用手機掃描即時閱讀！
