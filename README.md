# 埔心基督徒聚會處週報 - 手機專用直式互動資訊網

> **教會年度目標**：《全心倚賴耶和華、一切事上認定主》  
> **目前收錄期數**：第 1516 期（主後 2026 年 10 月 18 日最新出刊）及 第 1515 期（主後 2026 年 10 月 11 日前期存檔）  
> **會堂地址**：桃園市楊梅區埔心文化街 177 號

## 專案核心特色與設計規格

本專案將傳統教會週報 PDF 轉化為**手機專用直式互動網頁 (Mobile-First Web App)**，針對長輩閱讀習慣、手機直式手持操作、靈修敬拜與肢體互動進行深度客製化。

### 1. 手機專用直式版面 (Mobile-First Portrait)
- **版面規格**：設定 `max-width: 480px`，電腦上以精緻手機機身居中展示，手機瀏覽器全螢幕貼合並完整支援安全區（Safe Area Insets）。
- **常駐底部 App 導航列**：提供「首頁」、「崇拜程序」、「教會消息」、「代禱事項」、「服事聚會」、「資訊徵信」六大分頁，點擊流暢滑動切換。

### 2. 跨期數瀏覽切換功能 (Issue Switcher)
- 頂部設有**期數切換器**，可一鍵無縫在 **「第 1516 期（最新）」** 與 **「第 1515 期（前期）」** 之間即時切換。
- 切換時伴隨水晶琴鐘提示音，全站金句、講台信息、崇拜程序、消息、代禱與服事表同步動態更新。

### 3. 長輩友善字級分級 (嚴格限制：字體不要太小)
- 預設基底字級 17.5px、標題 24px～30px，採深灰藍（`#1e293b`）高對比文字與暖白底色。
- 頂部提供 **標準 (A)**、**放大 (A+)**、**特大 (A++)** 三級快速縮放，設定自動記憶於手機瀏覽器。

### 4. 即時全站關鍵字檢索 (Search & Highlight)
- 頂部一鍵展開搜尋列，支援跨區塊即時檢索（如搜尋講員「葉文漢」、事工「大掃除」、求醫「苑玲」、奉獻「100000」）。
- 自動計算匹配筆數，並以鮮豔黃色 `<mark>` 高亮醒目標註所有符合文字。

### 5. 明亮豐富色彩與流暢動畫
- **溫暖配色**：晨曦暖金琥珀（`#d97706`）、靈性典雅靛藍（`#4338ca`）、生機翡翠綠（`#059669`）、喜樂玫瑰粉（`#e11d48`）。
- **微互動動畫**：
  - 壽星祝賀：點擊「獻上祝福」發射繽紛紙花彩帶（Canvas Confetti）與豎琴琶音。
  - 守望代禱：點擊「我已同心代禱」播放阿們和弦並飄出飛升愛心粒子（❤️ ✝️），自動累計代禱次數。
  - 經文展開：宣召詩篇、講道經文與主禱文抽屜式平滑展開與彈窗研讀。

### 6. 零外部依賴 Web Audio 合成音效
- 採用瀏覽器原生 **Web Audio API** 運算發聲，無需額外下載任何 MP3 音檔，完全離線可用且無版權限制。
- 內建：觸控微音、本週金句清澈水晶鐘聲（E5-G#5-B5-E6）、代禱「阿們」三和弦、歡慶豎琴撥弦音階。
- 頂部設有一鍵靜音/開啟開關。

## 上傳 GitHub 與啟用 GitHub Pages 教學

請依照以下步驟將專案部署至 GitHub Pages：

### 步驟 1：在 GitHub 建立 Repository
1. 登入 [GitHub](https://github.com/)。
2. 點選右上角 **「+」** ➔ **「New repository」**。
3. 命名 Repository（例如：`puxin-church-bulletin`）。
4. 勾選 **Public**（公開），點擊 **Create repository**。

### 步驟 2：上傳專案檔案
#### 方法 A：使用 Git 指令推送
```bash
# 1. 進入本專案資料夾
cd "c:\Users\USER\Desktop\AI works\週報手機"

# 2. 初始化 Git
git init
git add .
git commit -m "feat: 建立埔心基督徒聚會處手機互動週報"
git branch -M main

# 3. 綁定 GitHub 遠端庫 (請替換 <YOUR_USERNAME>)
git remote add origin https://github.com/<YOUR_USERNAME>/puxin-church-bulletin.git

# 4. 推送至 GitHub
git push -u origin main
```

#### 方法 B：使用 GitHub 網頁直接上傳（免裝 Git）
1. 在剛剛建立的 GitHub 倉庫頁面，點擊 **「uploading an existing file」**。
2. 將資料夾內的 `index.html`、`style.css`、`app.js`、`README.md` 拖曳至瀏覽器。
3. 點擊 **Commit changes** 儲存。

### 步驟 3：開啟 GitHub Pages 免費網站託管
1. 在儲存庫頁面點擊 **Settings**（設定）。
2. 在左側欄位點擊 **Pages**。
3. 在 **Branch** 選擇 `main`，路徑維持 `/ (root)`，按下 **Save**。
4. 等候約 1 分鐘重新整理，上方即會出現您的專屬網址：  
   `https://<YOUR_USERNAME>.github.io/puxin-church-bulletin/`

### 步驟 4：製作手機 QR Code
將生成的 GitHub Pages 網址使用線上免費 QR Code 產生器製作成行動條碼，印刷於紙本週報或分享至教會 LINE 群組，弟兄姊妹即可直接以手機掃描閱讀！

## 提示詞設計指南 (Prompt Engineering Guide)

日後若有最新一期週報（如第 1517 期），可直接使用此標準提示詞引導 AI 生成或更新代碼：

```markdown
【任務說明】：
請根據這份教會週報的最新 PDF 檔案，製作/更新為視覺豐富的手機專用直式互動資訊網頁 (Mobile-First Web App)。

【設計規範】：
1. 版面配置：手機直式專用（直式螢幕優化，寬度最大約 480px，支援長輩友善大字體與 A/A+/A++ 字級切換）。
2. 標題與風格：標題為「埔心基督徒聚會處週報」，採用溫暖明亮、生氣蓬勃的色彩體系（晨曦琥珀金 #d97706、靈性典雅藍 #4338ca、翡翠綠 #059669、喜樂粉 #e11d48）。
3. 互動音效：整合 Web Audio API 即時合成音階（祥和金句鐘聲、代禱阿們和弦、歡慶琴音），無需依賴外部音檔，並附帶靜音開關。
4. 檢索功能：具備頂部即時關鍵字搜尋框，能動態高亮匹配文字並統計出現數量。
5. 動畫效果：包含壽星與獎學金彩帶紙花特效、代禱飛升愛心微動畫、經文與主禱文抽屜收合展開。

【必要內容模組】：
- 頂部導航：教會名稱、期數切換標籤、全站搜尋框、字體切換、音效切換開關。
- 底部 Tab 導航列：
  1. 首頁：本週金句（含鐘聲與一鍵複製）、講台信息速報、壽星祝福（紙花按鈕）、教會聯絡與導航。

  4. 代禱事項：國際、肢體健康、教會事工、青年求學就業、入伍兵役，每項具備「為他代禱」互動累計按鈕。

  6. 資訊徵信：奉獻金額彙整、十一奉獻明細卡片、教牧同工聯絡清單。

【交付檔案】：
提供可直接於 GitHub Pages 部署的 index.html、style.css、app.js 及 README.md 檔案。
```
